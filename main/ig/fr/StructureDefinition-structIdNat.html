Profil du type de données: StructIdNat

URL officielle: https://interop.esante.gouv.fr/ig/fhir/pdlgc/StructureDefinition/structIdNat Version: 0.1.0
Draft à partir de 2026-08-07 Nom computable: StructIdNat

Identification nationale principale d’une structure propre aux SI de l'ANS et au CI-SIS 4.

L’identification nationale d’une structure est construite selon le tableau dessous :

  • 0 + Identifiant cabinet ADELI
  • 1 + N° FINESS 2 + N° SIREN
  • 3 + N° SIRET
  • 4 + N° RPPS-rang
  • Néant + N° technique

Utilisations:

  • Utilise ce/t/te Profil de type primitif: PDLGC Index and XDM AuthorInstitution

Vous pouvez également vérifier les usages dans le FHIR IG Statistics
