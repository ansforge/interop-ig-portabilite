# PDLGC Fournisseur Destinataire - Portabilité des Données LGC v0.1.0

## ActorDefinition: PDLGC Fournisseur Destinataire 

 
Fournisseur de LGC recevant les données en vue de leur intégration. Il est tenu d'une obligation de moyens pour l'import dès lors que le format réceptionné est conforme au référentiel.
