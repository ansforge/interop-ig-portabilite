Modèle logique: PDLGC Manifest

URL officielle: https://interop.esante.gouv.fr/ig/fhir/pdlgc/StructureDefinition/pdlgcManifest Version: 0.1.0
Draft à partir de 2026-08-07 Nom computable: PDLGCManifest

Le fichier MANIFEST.XML porte les métadonnées globales de l'export (nombre de dossiers patients, volumétrie, éléments d'intégrité), distinctes des métadonnées XDM portées par chaque METADATA.XML patient

Utilisations:

  • Utilise ce/t/te Modèle logique: PDLGC Archive Portabilite

Vous pouvez également vérifier les usages dans le FHIR IG Statistics
